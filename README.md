# ЛËН Производство

[Открыть дашборд](https://uniconsulting.github.io/len-production-dashboard/)

Партнёрская модель производства в Ульяновске на 60 месяцев с декабря 2026 года. По умолчанию открыт план роста до загрузки выше 80% в декабре 2027 года. В меню сценария доступны также постоянные портфели на 22, 30 и 40 партий. На экране «Обзор» можно выбрать месяц, изучить состав партии и открыть быстрые ответы об оборачиваемости, выплатах и вложениях выбранного участника. Прямая ссылка на ответы заканчивается на `/#faq`. В разделе производства доступны все 12 принтеров. В разделе выплат можно выбрать участника и правило распределения прибыли. Кнопка «Поделиться» сохраняет выбранные параметры в ссылке.

На обзоре выручка распределена по группам принтеров. Выбор месяца на ленточном графике обновляет всю страницу. Радиальная шкала показывает занятые машино-часы в долях общего фонда; загрузку относительно собственного фонда группы можно посмотреть в разделе «Производство». Ряд под основными показателями показывает операционные поступления и платежи, состав затрат и план партий.

## Локальный просмотр

Из корня репозитория запустите:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000/. HTML, CSS, модули JavaScript, шрифты и набор данных раздаются как статические файлы. GitHub Pages публикует корень ветки main.

## Финансовые данные

data/model.json содержит рассчитанные сценарии и помесячные агрегаты проверенной модели от 10 ноября 2026 года. Денежные показатели приведены в рублях. Для выручки и чека применяется база без НДС. Параметры сценариев и условия выплаты дивидендов доступны в самом интерфейсе.

Скрипт scripts/export-model.mjs обновляет агрегаты из рабочей книги при наличии среды с пакетом @oai/artifact-tool. Входная книга с расчётными листами хранится отдельно. Для статической публикации достаточно данных, уже включённых в репозиторий.

Для текста и заголовков используется Garet Book от Type Forward; Doto Rounded — для основного показателя выручки. Оригинальные файлы шрифтов и лицензии находятся в assets/fonts/.
